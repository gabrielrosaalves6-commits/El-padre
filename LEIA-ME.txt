COMO PUBLICAR NO GITHUB PAGES
1. Extraia este ZIP.
2. Entre no seu repositório do GitHub.
3. Clique em Add file → Upload files.
4. Envie index.html para a raiz do repositório.
5. Se o GitHub perguntar, confirme substituir o arquivo existente; depois clique em Commit changes.
6. Se o GitHub Pages já estava funcionando, normalmente não precisa alterar Settings → Pages de novo.

As fotos e a música precisam de internet. A música toca por meio do player oficial do YouTube; não há arquivo de música protegido por direitos autorais incluído no ZIP.
